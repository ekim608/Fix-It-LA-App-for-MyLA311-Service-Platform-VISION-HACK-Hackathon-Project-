# Fix It LA App

This is a prototype for an app called "Fix it LA", built for the "Vision Hack" Hackathon in South Los Angeles. It automates and streamlines the process of finding, filling out, and submitting forms on MyLA311, the City of Los Angeles' online platform that allows citizens to report issues and submit city service requests. Using Web Speech API and the Google Gemini 3.6 Flash vision model, users can type, verbally describe, or take a picture of an issue that needs to be serviced. The descriptions and/or pictures are then analyzed and the appropriate service request form is filled out with all the necessary information.

Try it now using this link! (For optimal experience, mobile device or tablet is preferred): https://form-find.vercel.app/
